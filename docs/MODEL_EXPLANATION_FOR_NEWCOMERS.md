# 돼지 정상 행동 기준선 모델 설명서

이 문서는 이 프로젝트를 처음 보는 사람이 현재 모델로 무엇을 했는지 이해할 수 있도록 작성한 설명서입니다. 핵심은 지금 데이터를 대부분 정상 데이터로 보고, “정상적인 돼지와 돈방은 대략 이런 행동 리듬을 보인다”라는 기준선을 만드는 것입니다.

## 1. 이 프로젝트의 목적

이 프로젝트의 목표는 돈사 안 돼지들의 정상 행동 패턴을 먼저 학습해 기준선을 만드는 것입니다.

현재 사용한 데이터는 대부분 정상적인 상황에서 관측된 데이터로 간주합니다. 그래서 모델은 “이상한 돼지”를 직접 배우는 것이 아니라, 정상적인 돼지와 돈방의 행동 흐름을 먼저 배웁니다.

나중에 새 데이터가 들어왔을 때 이 정상 기준선에서 크게 벗어나면, 그 구간을 이상 후보로 표시합니다. 현재 모델은 “질병 확진”이나 “문제 상황 확정”을 직접 판정하는 모델이 아닙니다.

## 2. 사용한 데이터

현재 사용한 데이터는 AI Hub의 양돈 스마트축사 데이터 중 돼지 행동과 키포인트 라벨입니다.

원본 라벨에는 돼지의 행동 종류와 위치 정보가 들어 있습니다. 주요 행동 라벨은 다음과 같습니다.

- Lying: 누워 있음
- Standing: 서 있음
- Walking: 걷기
- Running: 뛰기
- Suckling: 젖먹기
- Searching: 탐색
- Feedbox: 사료통 주변
- Watercup: 급수기 주변

다운로드한 원본 라벨은 그대로 모델에 넣지 않았습니다. 먼저 분석하기 쉬운 표 형태로 변환했고, 이후 시간 단위 활동량 데이터로 다시 가공했습니다.

## 3. 데이터가 모델에 들어가기까지의 흐름

전체 흐름은 다음과 같습니다.

1. AI Hub 원본 라벨 다운로드
2. XML 라벨을 CSV 형태로 정리
3. 프레임 단위로 행동과 위치 특징 추출
4. 10분 단위 시계열 데이터로 변환
5. 24개 구간씩 묶어 모델 입력 데이터 생성
6. 정상 행동 기준선 모델 학습
7. 검증 데이터가 정상 기준선에서 얼마나 벗어나는지 확인

현재 모델 입력은 영상 자체가 아닙니다. 영상에서 추출된 행동 개수, 행동 비율, 위치 중심, 움직임 변화량 같은 숫자 특징입니다.

## 4. 만든 특징값

모델은 돼지의 개별 이미지를 직접 보는 대신, 일정 시간 동안의 행동 패턴을 숫자로 요약한 값을 봅니다.

대표적으로 사용한 특징은 다음과 같습니다.

- 프레임 수
- 돼지 키포인트 라벨 수
- 전체 키포인트 수
- 활동 행동 수와 비율
- 휴식 행동 수와 비율
- 돼지 위치 중심의 이동량
- 위치 중심의 평균과 표준편차
- 돼지가 차지하는 영역의 크기
- 누움, 섬, 걷기, 뛰기, 젖먹기, 탐색 행동의 개수와 비율

즉, 모델은 “돼지가 정확히 어떤 병에 걸렸다”를 배우는 것이 아니라 “정상적인 시간대별 행동 리듬은 어떤 모습인지”를 배우는 방식입니다.

## 5. 학습한 모델

현재 사용한 핵심 모델은 LSTM Autoencoder입니다.

쉽게 말하면, 이 모델은 정상적인 시간 흐름을 압축했다가 다시 복원하는 연습을 합니다. 평소와 비슷한 행동 패턴은 잘 복원되기 때문에 오차가 작고, 평소와 다른 패턴은 잘 복원하지 못해서 오차가 커집니다.

이 복원 오차가 작은 구간은 정상 기준선과 비슷하다고 보고, 복원 오차가 큰 구간은 정상 기준선에서 벗어난 후보로 봅니다.

현재 모델 설정은 다음과 같습니다.

- 입력 단위: 10분 단위 활동량 데이터
- 시퀀스 길이: 24개 구간
- 한 시퀀스가 보는 시간 범위: 약 4시간
- feature 수: 29개
- 학습 데이터 시퀀스 수: 699개
- 검증 데이터 시퀀스 수: 62개

추가로 Isolation Forest라는 전통적인 이상 탐지 모델도 baseline으로 실행했습니다. 이는 LSTM 모델 결과와 비교하기 위한 기준 모델입니다.

## 6. 추가 학습 후 한 일

처음 LSTM Autoencoder를 학습한 뒤, 저장된 최적 모델을 불러와 추가 학습을 진행했습니다.

그 다음 추가 학습된 모델로 검증 데이터를 다시 검사했습니다. 검사 방식은 다음과 같습니다.

1. 검증 데이터의 각 4시간 구간을 모델에 넣음
2. 모델이 해당 구간을 얼마나 잘 복원하는지 계산
3. 복원 오차가 큰 구간을 정상 기준선 이탈 후보로 표시
4. 단발성 후보는 확인 후보로만 두고, 3개 구간 이상 연속된 경우만 강한 이상 후보로 판단

이렇게 한 이유는 한 번 튀는 값이 항상 실제 이상상황은 아니기 때문입니다. 실제 운영에서는 센서 누락, 라벨 편차, 일시적인 움직임 변화 같은 이유로 단발성 오차가 생길 수 있습니다.

## 7. 현재 결과

추가 학습 후 최신 LSTM 모델의 검증 결과는 다음과 같습니다.

- 이상 판단 임계값: 0.599059
- 검증 시퀀스 수: 62개
- 원시 이상 후보: 1개
- 3연속 조건을 통과한 확정 이상: 0개

가장 높은 이상 후보는 다음 구간입니다.

- 시설 번호: 5
- pen 번호: 4
- 시간: 2021-09-09 07:50:00 ~ 2021-09-09 18:00:00
- 복원 오차: 0.608536
- 원시 이상 후보 여부: 예
- 확정 이상 여부: 아니오

해석하면, 이 구간은 모델 기준으로는 다른 구간보다 튀는 패턴을 보였지만, 비슷한 이상 신호가 3개 구간 이상 연속되지 않았기 때문에 최종 확정 이상으로 처리하지 않았습니다.

## 8. 결과를 어떻게 봐야 하는가

현재 결과는 “현재 데이터로 정상 행동 기준선이 만들어졌고, 검증 데이터 대부분도 그 기준선 안에 들어왔다”로 보는 것이 적절합니다.

단, 이것이 “돼지에게 아무 문제가 없다”는 뜻은 아닙니다. 현재 모델은 검증된 질병 이벤트나 실제 이상상황 정답 라벨을 학습한 것이 아니라, 정상 패턴에서 벗어난 정도를 보는 비지도 이상 탐지 모델입니다.

따라서 현재 결과의 의미는 다음과 같습니다.

- 모델이 기본 데이터 처리, 정상 기준선 학습, 기준선 이탈 확인까지 정상적으로 동작한다.
- 검증 데이터에서 단발성 이상 후보는 1개 있었다.
- 지속적인 이상 신호로 볼 만한 구간은 없었다.
- 앞으로 새 데이터가 들어오면 이 기준선과 비교해 벗어나는 정도를 볼 수 있다.

## 10. 지금 단계의 결론

현재 프로젝트는 “AI Hub 양돈 행동 라벨을 이용해 돈방 단위 정상 행동 기준선을 만들고, 새 데이터가 이 기준선에서 얼마나 벗어나는지 확인하는 전체 파이프라인”까지 구축된 상태입니다.

즉, 원본 데이터 다운로드부터 정제, feature 생성, 시계열 변환, 정상 기준선 학습, 추가 학습, 기준선 이탈 확인, 보고서 생성까지 한 번 실행 가능한 구조가 만들어졌습니다.

다음 단계는 정상 기준선을 더 튼튼하게 만드는 일입니다. 이를 위해서는 더 많은 AI Hub 파일을 연결하고, 돈방별 기간을 넓히고, 실제 현장에서 정상으로 확인된 기간을 더 많이 쌓는 것이 우선입니다. 이후 실제 이상상황으로 확인된 사례가 생기면 그 구간을 따로 표시해 기준선 이탈 결과가 현장 판단과 맞는지 검증하면 됩니다.
